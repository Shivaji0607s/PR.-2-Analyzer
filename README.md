# 📊 Retail Data Analyzer – Advanced Excel Project

## 📌 Project Overview

**Retail Data Analyzer** is an advanced Microsoft Excel data analysis project designed to analyze retail sales, customer purchasing behavior, profitability, discount impact, and monthly sales performance.

This project uses Excel's powerful data analysis features, including formulas, Conditional Formatting, What-If Analysis, Data Analysis ToolPak, PivotTables, and interactive visualizations to transform raw retail data into meaningful business insights.

## 🎯 Project Objectives

- Analyze customer purchasing patterns and sales performance.
- Identify top-performing customers based on total purchases.
- Evaluate the impact of discounts on overall profitability.
- Perform Linear Regression to understand the relationship between Sales and Profit.
- Calculate descriptive statistics for sales and profit.
- Analyze monthly sales trends and growth rates.
- Compare sales performance across different regions and product categories.
- Build a professional Excel dashboard for data visualization.

## 📂 Project Structure

The workbook contains the following worksheets:

| Worksheet | Description |
|---|---|
| Customer_Table | Main retail dataset containing customer, sales, discount, quantity, date, and profit information. |
| WHAT IF Analysis | Evaluates how different discount percentages affect total profit. |
| Regression Analysis & Statistic | Performs Profit vs Sales regression analysis using Analysis ToolPak. |
| Sales_Analysis | Descriptive statistical analysis of sales. |
| Profit_Analysis | Descriptive statistical analysis of profit and order dates. |
| Histogram | Frequency distribution of sales using histogram analysis. |
| MONTHLY SALES GROWTH ANALYSIS | Calculates monthly sales and growth percentages. |
| FILTER(), INDEX(), MATCH() | Identifies high-value customers and retrieves customer information. |
| Analyze Sales by Region | Analyzes total sales across different geographical regions. |
| Sales by Product Category | Compares sales performance across product categories. |
| Monthly Sales Trend | Analyzes monthly sales performance using a line chart. |
| Sales_Dashboard | Presents key analysis results through charts and visualizations. |

## 📈 Key Analysis Performed

### 1. Customer Analysis
- Highlighted the top 10 customers based on total purchases.
- Used Conditional Formatting to identify important customer records.
- Applied FILTER, INDEX, and MATCH functions to retrieve customer information.
- Identified customers with total purchases above ₹10,000.

### 2. What-If Analysis
- Evaluated the impact of changing discount percentages on total profit.
- Created an Adjusted Profit calculation.
- Used Excel Data Table to compare expected profit under different discount scenarios.

### 3. Linear Regression Analysis
- Performed regression analysis using Profit as the dependent variable and Sales as the independent variable.
- Evaluated Multiple R, R Square, Adjusted R Square, Standard Error, and regression coefficients.

**Regression Result:**

| Metric | Result |
|---|---:|
| Multiple R | 0.7736 |
| R Square | 0.5984 |
| Adjusted R Square | 0.5964 |
| Standard Error | 86.47 |
| Observations | 199 |

### 4. Descriptive Statistics
- Calculated Mean, Median, Standard Error, Standard Deviation, Variance, Minimum, Maximum, and other statistical measures.
- Analyzed sales and profit distributions.

### 5. Sales & Profit Analysis
- Created a histogram to understand sales frequency distribution.
- Analyzed sales performance across regions.
- Compared sales by product category.
- Evaluated monthly sales growth using percentage calculations and arrow indicators.

### 6. Dashboard & Visualization
Created a modern Excel dashboard incorporating:

- Sales by Region – Bar Chart
- Sales by Product Category – Pie Chart
- Profit vs Sales – Scatter Chart
- Monthly Sales Trend – Line Chart
